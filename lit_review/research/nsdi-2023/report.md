## Sources

- Paper list: the official USENIX NSDI '23 program page https://www.usenix.org/conference/nsdi23/technical-sessions fetched raw with `curl` and parsed for `/conference/nsdi23/presentation/...` links. Parsing the raw HTML yielded exactly 96 distinct main-track presentation entries (NSDI '23 merged its Spring and Fall accepted-paper cycles into one technical program; there are no workshop, poster or demo entries on this page).
- Cross-check of the count: the NSDI '23 Program Co-Chairs' message https://www.usenix.org/sites/default/files/nsdi23_message.pdf states that 96 papers were accepted across the two submission deadlines (about a 17% acceptance rate), matching the 96 parsed entries.
- DBLP (https://dblp.org/db/conf/nsdi/nsdi2023.html and the DBLP search API) was attempted as a second machine-readable source but returned an anti-bot interstitial, and the USENIX `/publications/proceedings/nsdi23` index is paginated across all USENIX venues and is not a reliable per-venue listing, so the chairs' message was used for the count cross-check instead.
- Abstracts, author lists and PDF URLs: each of the 96 `/conference/nsdi23/presentation/<slug>` pages was fetched individually; the direct PDF URL came from each page's `citation_pdf_url` meta tag.
- Code check: all 96 PDFs were downloaded and text-extracted, then scanned for github.com / gitlab / zenodo / bitbucket URLs so that official artifact links come from the papers themselves. Where a paper did not print a URL, the system name plus author/lab GitHub profiles and web search were checked, and candidate repositories were verified by fetching the repository landing page (title and README) to confirm it is the official artifact.
- Scratch files (fetched HTML, parsed lists, extracted repo URLs) are under `scratch/`.
