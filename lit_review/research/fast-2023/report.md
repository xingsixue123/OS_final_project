## Sources

- Official program / proceedings page: `https://www.usenix.org/conference/fast23/technical-sessions` — fetched with `curl` and parsed for every `/conference/fast23/presentation/...` link. 29 unique links, of which one (Andy Warfield, "Building and Operating a Pretty Big Storage System") is the keynote address, not a main-track paper. That leaves **28** main-track papers.
- Cross-check 1: the proceedings table of contents PDF `https://www.usenix.org/sites/default/files/fast23_contents.pdf` — its paper list matches the program page exactly, title for title, in the same session order.
- Cross-check 2: the Program Co-Chairs' message `https://www.usenix.org/sites/default/files/fast23_message.pdf` states verbatim: "FAST '23 received 122 submissions ... Of these, we accepted 28 papers, for an acceptance rate of 23%." This confirms 28.
- DBLP (`dblp.org/db/conf/fast/fast2023.html` and the DBLP search API) was attempted as a third source but returned an anti-bot interstitial for every request, so the two USENIX-official sources above were used instead.
- Per-paper abstracts and PDF links were taken from each `/conference/fast23/presentation/<author>` page. Code availability was checked by downloading all 28 paper PDFs and grepping them for repository URLs, plus GitHub code search and web search for the papers with no URL in the PDF.
