## Sources

Primary list: the official SOSP 2026 accepted-papers page,
<https://sigops.org/s/conferences/sosp/2026/accepted.html>, fetched with `curl` and parsed
from the raw HTML. An important parsing trap: that page is built from the SOSP 2024
template and still carries the whole 2024 accepted list inside an HTML comment
(`<!-- ... -->`) directly after the 2026 list. A naive tag-strip yields 105 entries; after
removing commented-out markup the real 2026 list is **62** papers.

Cross-check 1: the official conference schedule page,
<https://sigops.org/s/conferences/sosp/2026/schedule.html>, parsed for `<ul class="papers">`
session entries. It yields exactly 62 paper titles and the title set matches the accepted
page one-for-one.

Cross-check 2: <https://paper.lingyunyang.com/reading-notes/conference/sosp-2026> states the
SOSP 2026 acceptance rate as "15.9% (= 62 / 390)", independently confirming 62 accepted
papers. This page also supplied two artifact links (Janus, SkVM).

Cross-check 3: <https://pchaigno.github.io/academic/2026/08/03/sosp-2026-papers.html>
(published 2026-08-03, updated 2026-09-08) reproduces the list with preprint links and
abstracts; it contains 62 entries, 60 with titles identical to the official page and 2 with
minor wording differences (Anchor, Ave). This was the main source of abstracts - 32 of the
62 papers have a public preprint.

DBLP has no `conf/sosp/2026` entry yet (the conference runs 2026-09-29 to 2026-10-02 in
Prague, so proceedings are not published) and dblp.org served an anti-bot page to `curl`;
the ACM DL likewise has no 2026 proceedings. For that reason most papers have no official
PDF and no artifact yet - artifact evaluation has not happened. Where a paper had no
preprint I used the authors' group pages (e.g. Tsinghua storage group publication list,
TELOS lab at PKU) to confirm the entry, and the GitHub REST search API plus direct URL
checks to look for official code.

Additional per-paper checks: arXiv abstract pages were fetched directly to confirm titles
and, where an HTML rendering existed, grepped for github.com / gitlab.com / zenodo.org URLs
to find author-declared artifacts (this is how the LLM-42 and M2K repos were found). The
arXiv Atom API returned HTTP 429 from this host throughout, so the arXiv web search UI was
used instead.
