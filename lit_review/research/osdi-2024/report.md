Paper list: the official USENIX program page https://www.usenix.org/conference/osdi24/technical-sessions fetched with curl and parsed for distinct /conference/osdi24/presentation/ links - 53 unique papers. Every paper page and PDF was then downloaded individually (53 pages 53 PDFs) which confirmed 53 distinct entries.

Cross-check 1 - session arithmetic on the same program page - Memory Management 6 Low-Latency LLM Serving 5 Distributed Systems 4 Deep Learning 5 Operating Systems 5 Cloud Computing 5 Formal Verification 5 Cloud Security 4 Data Management 4 Analysis of Correctness 5 ML Scheduling 5 = 53 papers plus one joint keynote and two poster sessions which are not papers.

Cross-check 2 - DBLP (https://dblp.org/db/conf/osdi/osdi2024.html) and the USENIX /proceedings URL could not be used - DBLP serves an Anubis bot-check page to curl and to WebFetch and the proceedings URL returns 404. Instead the Semantic Scholar bulk API (venue OSDI year 2024) was used - it returns 52 records of which 5 are misattributed (one front-matter record and four OSDI 2025 preprints - DeDe BlitzScale DecDec Mirage) and it is missing 6 papers that are on the official program. After reconciliation every Semantic Scholar record that is genuinely OSDI 2024 appears in the 53-paper list so the official program page is used as authoritative.

Code check: for every surviving paper the PDF text was searched for github/gitlab/zenodo URLs (the official link is usually in the abstract footnote or artifact appendix) and the repository URL was verified to return HTTP 200. Where the paper gave no URL the project website author GitHub account and GitHub search were checked.
