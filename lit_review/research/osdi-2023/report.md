## Sources

- Primary paper list: the official USENIX program page, fetched raw with `curl` and parsed for
  `/conference/osdi23/presentation/...` links —
  https://www.usenix.org/conference/osdi23/technical-sessions
  Parsing yielded 55 distinct presentation entries. The same page's `<h2>` session structure was
  parsed separately to confirm that the 55 entries are exactly the papers in the 12 technical
  sessions (keynote, awards, breaks, poster sessions and closing remarks are separate headings and
  carry no presentation link). Adding `?page=1` / `?page=2` returns the identical set, so the page
  is not paginated.
- Per-paper pages (abstract, PDF link, any author-supplied code URL) were fetched individually for
  all 55 papers from `https://www.usenix.org/conference/osdi23/presentation/<slug>`.
- Cross-check of the count: https://papers.cool/venue/OSDI.2023 reports "Total: 55" for OSDI 2023,
  matching the USENIX count. DBLP (dblp.org and dblp.uni-trier.de) was tried as a third source but
  both the HTML pages and the search API are behind an anti-bot interstitial from this host, so
  DBLP could not be used.
- Artifact / code check: the OSDI '23 artifact-evaluation results page
  https://sysartifacts.github.io/osdi2023/results (32 artifact submissions, with direct repository
  URLs) was parsed for repository links; remaining candidates were resolved via the paper PDF
  (`pdftotext` + URL grep), author / lab GitHub organisations, and the GitHub API.
