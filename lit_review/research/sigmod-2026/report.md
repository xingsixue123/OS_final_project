## Sources

Primary list: the official SIGMOD 2026 accepted-papers page,
https://2026.sigmod.org/sigmod_papers.shtml . It states that the SIGMOD 2026 research
track consists of four submission rounds, published as four PACMMOD issues:
Round 1 = PACMMOD 3(4) (Sept 2025), Round 2 = PACMMOD 3(6) (Dec 2025),
Round 3 = PACMMOD 4(1) (Feb 2026), Round 4 = PACMMOD 4(3) (June 2026).
The conference itself was held 31 May - 5 June 2026 in Bengaluru, India.

Enumeration: I fetched the raw DBLP volume pages for PACMMOD Volume 3
(https://dblp.org/db/journals/pacmmod/pacmmod3.html) and Volume 4
(https://dblp.org/db/journals/pacmmod/pacmmod4.html) with curl (DBLP is behind an
Anubis proof-of-work gate, which I solved programmatically) and parsed every entry in
the four issues above. That yields 358 records; removing the 4 per-issue editorials and
5 "Corrigendum:" records leaves 349 research papers.

Cross-check: the official page lists 349 paper titles. Diffing the two lists, every
DBLP paper matches an official-page title except four spelling variants
("Mergeable"/"Mergable", "SieveSketch"/"SeiveSketch", "Drama"/"DRAMA",
"Negotiating"/"Negotiation") and one paper, "LSM-Raft: Optimizing Raft for LSM-tree
Store", that appears in PACMMOD 3(6) on DBLP but not on the conference page (the
official page also contains two duplicate AgentTune entries, which accounts for the
count matching exactly at 349). I used the DBLP list as canonical.

Note: DBLP labels PACMMOD 3(6) as "SIGMOD Conference 2025"; that label is wrong
(the issue appeared in December 2025, after SIGMOD 2025), and the conference site is
authoritative, so 3(6) is counted as a SIGMOD 2026 round here.

PODS papers (PACMMOD 3(5) and 4(2)), demos, industrial-track and tutorial papers are
not part of this count.

Paper/PDF links: PACMMOD is fully open access under ACM OPEN, so the ACM DL landing
page (https://doi.org/10.1145/...) and the matching PDF
(https://dl.acm.org/doi/pdf/10.1145/...) are given for every included paper.

Code check: for every included paper I looked for an official repository via the
abstract text, the GitHub repository search API (two rounds of queries per paper), the
public repository listings of the authoring labs that I could identify
(saltsystemslab, BU-DiSC, neurdb, thustorage, eth-easl, asu-cactus, ZJU-DAILY,
SJTU-Liquid, future-file-format), and targeted web searches. ACM DL artifact pages are
behind Cloudflare and could not be read from this machine, and the arXiv API rate-limited
me, so where no repository surfaced I report "unknown" rather than claiming the code is
unreleased. No paper is marked out-no-code: I could not positively confirm absence of
code for any in-scope paper.
