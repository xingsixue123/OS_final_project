- Official electronic proceedings: `https://proceedings.mlsys.org/paper_files/paper/2025` (Proceedings of Machine Learning and Systems 7, MLSys 2025). Fetched the raw HTML with `curl` and parsed the `<ul class="paper-list">` items. The page's own counter says "61 papers" and the parsed list has 61 `<li>` entries, every one tagged `data-track="conference"` (single main track; MLSys 2025 has no separate industry track in the proceedings).
- Cross-check: the conference site's paper index `https://mlsys.org/virtual/2025/papers.html` also yields exactly 61 distinct poster entries. Title sets from the two sources match on 60 of 61; the single difference is one paper that was renamed between the program and the proceedings ("GSplit: ... via Split-Parallelism" on mlsys.org vs "SPA: ... via Probabilistic Splitting" in the proceedings) - same authors, same paper.
- DBLP (`dblp.org/db/conf/mlsys/mlsys2025.html`) and the OpenReview API were both unreachable from this host (Anubis bot challenge / OpenReview challenge verification), so the mlsys.org program index was used as the second source instead.
- Abstracts and PDFs were taken from each proceedings paper page; the 61 PDFs were downloaded and converted to text to look for official code URLs in the abstract, footnotes and artifact appendices.
- Code checks beyond the PDFs: GitHub repository search by system name, author GitHub accounts and homepages, targeted web search, and an HTTP check that every repository URL listed below actually resolves.
