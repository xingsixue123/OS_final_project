## Sources

Paper list built from two independent sources and cross-checked.

1. Official program: https://asplos-conference.org/asplos2025/program.html (fetched with curl and parsed). Every
   `div.paper` entry carries an ACM DOI. The program contains 184 talks split over three DOI prefixes:
   24 x `10.1145/3622781` , 72 x `10.1145/3669940` , 88 x `10.1145/3676641` .
2. Crossref REST API (`api.crossref.org/works/...`) for each of those DOIs, which resolves the proceedings each
   paper actually belongs to:
   - `10.1145/3669940` = *ASPLOS '25, Volume 1* (72 papers)
   - `10.1145/3676641` = *ASPLOS '25, Volume 2* (88 papers)
   - `10.1145/3622781` = *ASPLOS '24, Volume 4* (24 papers, published 2024-04-27). These were presented in the
     ASPLOS 2025 session program but are formally ASPLOS 2024 publications, so they are **not** counted here -
     they belong to the ASPLOS 2024 venue-year.
3. A third ASPLOS '25 volume exists that is not in the March-2025 session program: `10.1145/3676642` =
   *ASPLOS '25, Volume 3* (published 2025-08-06). It was found via a Semantic Scholar venue query
   (`api.semanticscholar.org/graph/v1/paper/search/bulk?venue=ASPLOS&year=2025`), which surfaced DOIs with that
   prefix. Its contents were enumerated by probing the contiguous DOI-suffix range through Crossref: 16 research
   papers (`3676642.3736113`-`3736129`, `...3736122` is unassigned) plus two keynote abstracts
   (`3676642.3729205/3729206`, pages 1-4) and one contest report (`3676642.3736399`, pages 5-17). The keynotes and
   the contest report are not main-track research papers and are excluded.

**TOTAL_PAPERS = 72 (Vol 1) + 88 (Vol 2) + 16 (Vol 3) = 176 ASPLOS '25 main-track papers.**

Completeness check: Crossref page ranges for every enumerated paper were sorted and checked for gaps. Volume 1
covers pages 1-1165 with no gap, Volume 2 covers pages 1-1421 with no gap, Volume 3 covers pages 18-281 with no gap
(pages 1-17 are the keynote abstracts and the contest report). Unassigned DOI suffixes inside each range
(`3707233`, `3707283`, `3716024`, `3736122`) and the suffixes immediately outside each range were probed and all
return 404 from Crossref, so no paper is missing. DBLP was unreachable (all mirrors are behind an anti-bot
challenge) and dl.acm.org returns 403 to scripted requests, so Crossref + the official program + Semantic Scholar
were used instead.

Abstracts for the topic/machine screen came from OpenAlex (`api.openalex.org`, 159/176 papers had an abstract);
the remaining ones were screened from the title plus targeted web lookups. Code was looked for via the GitHub
repository search API (searching by system name), targeted web search, and direct probing of likely
author/lab repository URLs. ASPLOS 2025 does not publish an artifact-evaluation results page on
sysartifacts.github.io, and the conference site has no artifact index, so there is no single authoritative
artifact list to consult.

PDF links are the ACM Digital Library open-access PDFs (`dl.acm.org/doi/pdf/...`); ASPLOS '25 proceedings are
published under ACM OPEN, which OpenAlex confirms by listing those URLs as best open-access locations.
