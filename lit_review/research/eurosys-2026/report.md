A normalized title-set comparison against the conference page gave 0 papers on one side and not the other, so both sources agree on 138 main-track papers.
- DBLP (dblp.org, uni-trier and dagstuhl mirrors) and the ACM DL HTML pages are behind bot protection from this host, so Crossref was used as the second authoritative source instead.
- Artifact links: the EuroSys 2026 artifact evaluation results page https://sysartifacts.github.io/eurosys2026/results, parsed from raw HTML. It lists 54 evaluated artifacts (29 available, 54 functional, 54 reproduced) with repository or Zenodo URLs, matched back to the paper list by normalized and fuzzy title matching. - Abstracts: Semantic Scholar Graph API batch lookup by DOI (all 138 resolved). Repository checks for papers without an AE artifact used GitHub API search, targeted web search and raw README fetches.
