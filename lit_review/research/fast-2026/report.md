## Sources

- Primary list: USENIX **FAST '26 Technical Sessions** program page, fetched raw with `curl` and parsed
  (`https://www.usenix.org/conference/fast26/technical-sessions`). The page yields 46 `/conference/fast26/presentation/...`
  entries. Two of them are not main-track papers and were dropped: the keynote address by Erez Zadok
  ("Everything You Always Wanted to Know about Storage Analysis") and the "FAST '26 Test of Time Award
  Presentation". Neither has a paper PDF in the proceedings. That leaves **44** main-track papers.
- Every one of the 44 was confirmed to be a real proceedings paper by fetching its presentation page and
  verifying a `https://www.usenix.org/system/files/fast26-<slug>.pdf` proceedings PDF exists (44/44 had one;
  the keynote and the award talk had none).
- Cross-check: USENIX **FAST '26 Spring Accepted Papers** page
  (`https://www.usenix.org/conference/fast26/spring-accepted-papers`) lists 13 papers; all 13 appear in the
  44 (FAST runs two submission cycles, so the remaining 31 are the Fall cycle). The `fall-accepted-papers`
  URL 404s — the fall list was folded into the program page.
- DBLP (`dblp.org/db/conf/fast/fast2026.html`) was attempted as a second independent source but is behind an
  anti-bot challenge (Anubis) and returned no data; the Spring-accepted-papers page was used instead.
- Code check: for each surviving paper, the full proceedings PDF was downloaded and text-extracted, and
  searched for availability statements and artifact appendices; then the GitHub search API was used on the
  system name, plus the authors' lab organizations (`thustorage`, `WiscADSL`, `SJTU-IPADS`, `adslabcuhk`,
  `SJTU-Storage-Lab`, `dgist-datalab`, `TUM-DSE`, `nicexlab`). All included repo URLs were HTTP-checked.
- Scratch files (raw HTML, parsed lists, PDFs, extracted text) are under `scratch/`.
