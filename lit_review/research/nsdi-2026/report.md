That the per-paper page count, the program entry count and the PDF count all equal 150 is the count confirmation.

- Code check: all 150 proceedings PDFs were downloaded and text-extracted, and every github.com / gitlab.com / zenodo.org / bitbucket.org / codeberg.org / huggingface.co URL in each paper was collected and read in context to separate the authors' own artifact from cited third-party software.
