## Sources

- Primary list: USENIX NSDI '24 Technical Sessions program, https://www.usenix.org/conference/nsdi24/technical-sessions (fetched with curl and parsed, not summarized). The page contains exactly 112 `node-paper` entries, each with a distinct `/conference/nsdi24/presentation/<slug>` URL; those 112 slugs are the main-track paper list. Session headings on the page confirm that the non-paper items (breakfasts, breaks, opening remarks, awards, luncheon, poster session) carry no presentation URL and are therefore not counted.
- Per-paper pages: all 112 `https://www.usenix.org/conference/nsdi24/presentation/<slug>` pages were fetched for title, authors, abstract and the direct PDF link (`/system/files/nsdi24-<slug>.pdf`).
- Full texts: all 112 official PDFs were downloaded and converted to text, then scanned for GitHub / GitLab / Zenodo / Bitbucket URLs, which is how most of the official artifact links below were established (NSDI '24 has no artifact-evaluation results page - https://sysartifacts.github.io/nsdi2024/ and https://www.usenix.org/conference/nsdi24/artifact-evaluation both return 404).
- Cross-check: DBLP (dblp.org and dblp.uni-trier.de, both HTML and the publication API) was blocked by an anti-bot interstitial, and the Semantic Scholar bulk API returned HTTP 429, so an external count could not be obtained. Instead the count was cross-checked inside the authoritative source in two independent ways: 112 `node-paper` article containers and 112 unique presentation URLs, which agree. NSDI is a USENIX-only venue (not in the ACM DL), so the USENIX proceedings page is the authoritative table of contents.
- Code checks: paper PDFs and abstracts first; then GitHub repo landing pages / the GitHub API for existence and description; then GitHub search by system name for the papers with no URL in the PDF (Prequal, Vulcan, NIRVANA, QuickUpdate, Can't Be Late).
