## Sources

- Official accepted-papers page: https://www.sigmetrics.org/sigmetrics2026/accepted.html - 80 titles listed under the Summer (23), Fall (25) and Winter (32) POMACS deadlines. Fetched with curl and parsed from the raw HTML `<li><strong>` entries rather than summarized.
- Official program: https://www.sigmetrics.org/sigmetrics2026/program_at_a_glance.html - 23 technical sessions. Parsing the `program-session-paper` list items yields 83 entries, of which 3 are keynote/award speaker names with no DOI; the remaining 80 talk entries match the accepted-papers list exactly after Unicode normalization (0 titles in either list missing from the other). This page also gives, per paper, the SIGMETRICS abstract DOI (10.1145/3801489.x) and the POMACS article DOI, which I used for links.
- DBLP (dblp.org/db/conf/sigmetrics/sigmetrics2026.html and the POMACS volume pages) is behind an Anubis proof-of-work bot wall from this host and returned no usable data; ACM DL (dl.acm.org) returns Cloudflare 403 to both curl and WebFetch. So the cross-check is official site accepted-papers page vs official site program, two independently maintained pages, both from the venue.
- Abstracts for 76 of 80 papers came from the OpenAlex API by DOI, the remaining few from Semantic Scholar; the 4 with no abstract anywhere (#46 DNS, #52 queues, #68 quantum ECC, #72 Q-learning) are all clearly out of topic on title plus venue session.
- A secondary source (web search summary of the ACM DL proceedings front matter) quotes an acceptance figure of 81 of 481 submissions. Both venue-hosted pages list 80 talks, so I report 80 enumerated main-track papers; the discrepancy is most likely one withdrawn or not-presented paper.
- Code checks used: URLs printed in the abstract or paper body, arXiv or author-hosted or institutional-repository PDFs where the ACM copy was unreachable, GitHub repository search, and targeted web search on the system name plus authors.
