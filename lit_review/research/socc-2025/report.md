## Sources

- Official program: `https://acmsocc.org/2025/schedule.html` (fetched with `curl` and parsed).
  SoCC '25 was held online 2025-11-19 to 2025-11-21. The `accepted-papers.html` page on the
  official site is empty, so the full-program schedule page was used; it lists every talk
  grouped into 14 technical sessions (Serverless, Memory, Schedulers, Green Computing, Privacy,
  LLM Serving, Network, Consistency, Co-processors, Cloud-for-ML, Training, ML-for-Cloud,
  Infrastructure, Storage). Keynote, breaks, opening and closing remarks were excluded.
  This yields **67** main-track papers.
- Cross-check: Crossref REST API, `container-title:Proceedings of the 2025 ACM Symposium on
  Cloud Computing` (proceedings DOI prefix `10.1145/3772052`). Crossref reports
  `total-results: 67`, all of type `proceedings-article`, and every title matches the schedule
  one-to-one. Counts agree: **67**.
- DBLP (`dblp.org/db/conf/cloud/socc2025.html`) and the ACM DL proceedings page
  (`dl.acm.org/doi/proceedings/10.1145/3772052`) were both blocked to `curl`
  (Anubis bot-check and Cloudflare 403 respectively), so Crossref was used as the second
  authoritative source instead.
- Abstracts / full text: Semantic Scholar Graph API (20 abstracts), arXiv preprints, and author
  or lab copies of the PDFs (UT-SysML, ETH, HKU, VT, UChicago, Temple, Liège) were downloaded
  and searched for artifact URLs. ACM DL PDFs are not reachable from this host.
- Code check: repository URLs found in the paper full text where available, plus GitHub API
  repository search and authors'/labs' GitHub and publication pages. All repository URLs listed
  below were confirmed to return HTTP 200 (two resolved through a rename redirect).
