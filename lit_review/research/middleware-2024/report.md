## Sources

- Primary list: official conference site, "Accepted Paper List" page —
  https://middleware-conf.github.io/2024/program/accepted-paper-list/ — fetched raw with
  `curl` and parsed. The page groups papers by track; only the block headed "List of Accepted
  Papers in ACM/IFIP Middleware 2024 Main Conference" was used, which yields 39 titles.
  Workshop tracks (WoSC10, Mid4CC-24, Midd4DT-24, WoC'24), the Industrial Track, and the
  Demos/Posters/Doctoral Symposium block were excluded.
- Cross-check: Crossref REST API
  (`api.crossref.org/works?query.container-title=Middleware&filter=type:proceedings-article,...`).
  Crossref reports exactly 39 proceedings-articles whose container title is
  "Proceedings of the 25th International Middleware Conference" (proceedings DOI prefix
  10.1145/3652892). Titles match the official site one-for-one. Crossref separately lists 16
  Demos/Posters/Doctoral Symposium items, 7 Industrial Track items, and the workshop
  proceedings, confirming the track split. Counts agree: 39.
- DBLP (dblp.org/db/conf/middleware/middleware2024.html) and the DBLP JSON API were
  unreachable from this host — both are behind an Anubis anti-bot challenge. ACM DL
  (dl.acm.org) is behind a Cloudflare challenge, so per-paper landing pages and ACM PDFs could
  not be fetched; abstracts were obtained from the Semantic Scholar Graph API (batch lookup by
  DOI, all 39 returned abstracts), and full text was read from arXiv / author copies where
  available.
- Code check used: artifact/availability statements inside arXiv and author-copy PDFs (URI
  annotations plus text extraction), author and lab homepages, lab GitHub organizations
  (CARV-ICS-FORTH, DataStates, sacs-epfl, ssrg-vt, UWASL, Nokia-Bell-Labs, iQua), and GitHub
  repository search by system name. Middleware 2024 ran an "Artifacts Available / Functional"
  badge process (see the Call for Artifacts page) but publishes no public badge list, and the
  badges live on the ACM DL pages that are unreachable, so badges could not be used.
