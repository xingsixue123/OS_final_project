## Sources

- Primary list: USENIX FAST '25 technical sessions program, fetched raw with `curl` and parsed
  (`https://www.usenix.org/conference/fast25/technical-sessions`). The page yielded 39
  `/conference/fast25/presentation/...` entries; three are not papers (the "Honoring Erik Riedel"
  opening item, the keynote address by Seetharami Seelam, and the FAST '25 Test of Time Award
  presentation for SHARDS), leaving **36 main-track papers**.
- Cross-check: the official proceedings table of contents PDF
  (`https://www.usenix.org/sites/default/files/fast25-toc.pdf`, converted with `pdftotext`).
  It lists exactly the same 36 titles across the 8 sessions (File Systems, Cloud Storage,
  Machine Learning and Storage, More Machine Learning, Hardware Assist, Security/Integrity/
  Consistency, Compression and Deduplication, Storage Diversity and Heterogeneity). Counts agree.
- DBLP (`dblp.org/db/conf/fast/fast2025.html` and the DBLP search API) was blocked by an Anubis
  bot check from this host, and the USENIX `accepted-papers` page for fast25 is an empty stub,
  so the proceedings ToC PDF served as the second source.
- Per-paper detail: all 36 presentation pages and all 36 final-paper PDFs were downloaded into
  `scratch/pres/` and `scratch/pdfs/` and converted to text; code URLs were located by grepping
  the paper text (abstract footnotes, implementation sections, artifact appendices) and confirmed
  with the GitHub API / HTTP status checks. No per-paper "Artifacts Available" badges are shown
  on the USENIX FAST '25 pages (only two Distinguished Artifact Award notes), so the PDFs and
  GitHub search were the code-check route.
