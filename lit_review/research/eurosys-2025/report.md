## Sources

- Official accepted-papers page, both review cycles: https://2025.eurosys.org/accepted-papers.html - fetched with `curl` and parsed from the raw HTML (two tables, Spring 41 papers plus Fall 44 papers = 85).
- Crossref REST API for the proceedings container `Proceedings of the Twentieth European Conference on Computer Systems` (ACM DOI prefix 10.1145/3689031): 85 works, used for the canonical published titles, DOIs and page ordering. Query: `https://api.crossref.org/works?filter=container-title:Proceedings of the Twentieth European Conference on Computer Systems`.
- Cross-check: the two lists match 83 titles exactly and differ on two that were renamed between acceptance and camera-ready (`SpotHedge: Serving AI Models on Spot Instances` published as `SkyServe: Serving AI Models across Regions and Clouds with Spot Instances`, and `Jupiter: Pushing the Speed and ...` published without `the`). Both sources therefore agree on a count of **85 main-track papers**, and the published titles are used below.
- DBLP (`dblp.org/db/conf/eurosys/eurosys2025.html` and the search API) was attempted as a third source but is behind an Anubis anti-bot challenge and returned no data.
- EuroSys 2025 artifact-evaluation results: https://sysartifacts.github.io/eurosys2025/results - parsed for badges and artifact URLs (44 papers with a public artifact link, plus ParallelEVM which has Functional and Reproduced badges but no Artifacts Available badge and no link).
- Abstracts for the topic screen: Semantic Scholar Graph API batch lookup by DOI (85 of 85 abstracts retrieved). Individual paper PDFs (arXiv and author copies) were grepped for repository URLs where the artifact page had no entry.
- Code checks for papers with no artifact-page entry: GitHub repository search by system name and keywords, GitHub searches for `EuroSys 2025` / `EuroSys25` / `EuroSys '25` in repo names and descriptions, author and lab GitHub accounts, and the paper PDF. ACM DL pages themselves are behind Cloudflare and could not be fetched.
