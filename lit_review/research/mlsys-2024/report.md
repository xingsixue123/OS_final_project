## Sources

- Primary enumeration: the official MLSys 2024 proceedings table of contents,
  `https://proceedings.mlsys.org/paper_files/paper/2024` (Proceedings of Machine Learning
  and Systems, Volume 6). Fetched with `curl` and parsed with a regex over the
  `<a title="paper title" href="/paper_files/paper/2024/hash/...">` entries — 37 papers.
  Each paper's abstract page was fetched and its abstract + PDF link extracted
  (`scratch/papers.json`, `scratch/abs/`).
- Cross-check: the conference site's accepted-papers page,
  `https://mlsys.org/Conferences/2024/AcceptedPapers`. It contains exactly 37 author
  blocks (`<div class="indented">`), and every author list maps 1:1 onto a title in the
  proceedings list. Both sources therefore agree on 37 main-track (research-track)
  papers. MLSys has a single research track, so there is no workshop/industry/poster
  track to strip out.
- DBLP (`dblp.org/db/conf/mlsys/mlsys2024.html`) was attempted as a third source but is
  behind an anti-bot challenge (Anubis) and returned no data; the two sources above are
  authoritative and agree.
- Code checks: paper PDFs were downloaded and grepped for `github`/`gitlab`/`zenodo`
  URLs (`scratch/pdf/`), plus GitHub repo/search API lookups, author and lab GitHub
  accounts (e.g. `pratikfegade`, `hkeee21`, `oahzxl`, orgs `hpcaitech`, `SymbioticLab`),
  and targeted web searches for the two papers with no in-paper link.
