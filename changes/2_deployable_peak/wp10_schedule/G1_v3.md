## The exact table
A piecewise-constant table cannot equal a continuous power law everywhere. But the simulator evaluates g only at the `load_10m` values that occur at request timestamps.
- `src/g1v3.py:exact_table` enumerates every distinct request timestamp of the Region7 s0 trace (196,242), all ops.
- It computes their `load_10m` with the overlay's own `DemandLoad` (138,572 distinct values, 0 to 67.49 util-%).
- It builds one bucket per distinct value v. Bucket b covers [v_b, v_{b+1}), and its multiplier is g_pow(v_b), computed with `LoadAdaptiveThreshold.g`'s expression verbatim.
- JSON floats round-trip exactly. So every lookup returns the same double as the power law, and the bit-identical run confirms it end to end.
- The file (5.3 MB) is git-ignored: `work/tables/g1v3_exact_powerlaw_Region7_s0.json`.

This shows that the new code path (`LoadTableThreshold.g` via `bisect_right`, wiring, demand series) is the same mechanism as item 1.2. The WP10 tables differ from it only in their values.
