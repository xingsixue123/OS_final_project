## What this shows
- With default flags the v4 simulator and trainer are the frozen artifact (bit-identical results, series, histograms, counters; byte-identical models under pinned training).
- The v4 edit of `NewMLAP.batchAccept` leaves the alpha and 1.2b-table paths bit-identical to v3.
- The class-table code path (`LoadClassTableThreshold.g_item`, class index from the access's own feature vector) is the same mechanism as the 1.2b table: equal class rows reproduce the table run bit-for-bit. Class tables differ from 1.2b tables only in their values.
