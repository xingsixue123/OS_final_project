The task. Requests hit a flash cache in front of hard disks. A hit is free for the disks; a miss costs disk-head time. The admission policy decides, on each miss, whether to write the block into flash. Flash wears out, so the write rate is capped, here at 35.6 MB/s. The metric is P100: the busiest 10-minute window of disk utilization, because that is what disks are provisioned for. The data are Baleen’s public traces from Meta’s Tectonic storage system. Each trace comes from one storage cluster, which can span a whole datacenter, with thousands of storage nodes serving hundreds of applications. The paper names these seven clusters Region1 to Region7; the name is only an anonymous label, not a geographic region. Regions 1 to 3 were recorded in 2019, Region4 in 2021, and Regions 5 to 7 in 2023, each over several days: the first day is used for training, the rest for testing. Because a full trace is huge, it is downsampled to 0.1% of the blocks, keeping every access to those blocks, and the cache is scaled down to match. Different samples, s0, s0.1 and so on, are different 0.1% slices of the same cluster, so each one is a separate smaller workload. We run everything in Baleen’s own simulator, so our numbers are directly comparable with the paper.
